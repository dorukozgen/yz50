# Data Loader with tascib/turkish-llm-dataset

## 1. Setup

In this step the training data comes from the Hugging Face dataset [`tascib/turkish-llm-dataset`](https://huggingface.co/datasets/tascib/turkish-llm-dataset) instead of FineWeb-Edu. It is a Turkish pretraining corpus built from BellaTurca, Cosmos-Turkish-Corpus-v1.0 and FineWeb-2 Turkish, then cleaned and deduplicated. The text was tokenized into shards, and the shards are read with `DataLoaderLite`. The output in section 3 is the first batch returned by the data loader.

| Setting | Value |
|---|---|
| Dataset | [`tascib/turkish-llm-dataset`](https://huggingface.co/datasets/tascib/turkish-llm-dataset) (Hugging Face), Turkish, CC BY-SA 4.0 |
| Tokenizer | GPT-2 (`tiktoken`), `<\|endoftext\|>` at the start of every document |
| Shards | `dataset/`: 1 val + 4 train shards, 100,000,000 `uint16` tokens each |
| Data loader | `DataLoaderLite(B=16, T=1024, split='train')` |
| Printed batch | first `next_batch()`: `x` of shape (16, 1024) = 16,384 tokens from `edufineweb_train_000001.npy` |

| Shard | Split | Tokens | Documents (`<\|endoftext\|>` tokens) |
|---|---|---:|---:|
| `edufineweb_val_000000.npy` | val | 100,000,000 | 127,605 |
| `edufineweb_train_000001.npy` | train | 100,000,000 | 106,414 |
| `edufineweb_train_000002.npy` | train | 100,000,000 | 96,460 |
| `edufineweb_train_000003.npy` | train | 100,000,000 | 96,478 |
| `edufineweb_train_000004.npy` | train | 100,000,000 | 96,093 |
| **Total** | | **500,000,000** | **523,050** |

The file names keep the `edufineweb_` prefix from the video's script, but the shards contain the tokenized `tascib/turkish-llm-dataset` text, as the Turkish output below shows.

## 2. Data Loader

`DataLoaderLite` no longer reads `input.txt`. It now reads the token shards:

- `__init__` lists the files in `dataset/`, keeps the ones whose name contains the split (`train` or `val`), sorts them and loads the first one. For `split='train'` it finds the 4 train shards.
- `load_tokens` reads a shard with `np.load`, converts it from `uint16` to `int32` and then to a `torch.long` tensor.
- `next_batch()` takes `B*T + 1` consecutive tokens. `x = buf[:-1].view(B, T)` are the inputs and `y = buf[1:].view(B, T)` are the targets (the next token at every position). The position then moves forward by `B*T`. When the next batch would run past the end of the shard, the loader moves on to the next shard, and after the last shard it goes back to the first one.

To check the data, the first batch was decoded back to text row by row and printed:

```python
train_loader = DataLoaderLite(B=B, T=T, split='train')

x, y = train_loader.next_batch()
for i in range(x.size(0)):
    print(f"Sequence {i}:")
    print(enc.decode(x[i].tolist()))
    print("-" * 50)
```

## 4. Observations

- The data is Turkish text, and the Turkish characters (ç, ğ, ı, İ, ö, ş, ü) come back correctly after encode → `uint16` shard → decode. The GPT-2 tokenizer works on bytes, so it can encode any UTF-8 text, but it was trained mostly on English and splits Turkish words into many pieces: this batch has 16,384 tokens for 3,759 words, i.e. 4.36 tokens per word (about 1.3 for English FineWeb-Edu text).
- The rows are consecutive pieces of one long token stream. Each row continues exactly where the previous one stopped, even in the middle of a word: Sequence 0 ends with "... iş" and Sequence 1 starts with " doyumları", Sequence 2 ends with "anal" and Sequence 3 starts with "iz edilmiştir". This is because `next_batch()` cuts out `B*T` consecutive tokens and only reshapes them with `.view(B, T)`.
- `<|endoftext|>` marks the document boundaries. The batch contains 24 of them, so it holds 23 complete documents plus the end of one document at the start and the beginning of another at the end. A row can hold more than one document (Sequence 2 has pieces of three), and a document can continue into the next row.
- All documents in this batch are abstracts of Turkish education research papers (sample sizes, t-tests, ANOVA, scales). The documents are written to the shards in the order they are read from the dataset, so neighbouring documents usually come from the same source and one batch can be very uniform in topic. Samples from other places in the shards are news, sports and history texts, so the topic changes along the stream.
- The printed batch starts in the middle of a word ("elerinde ...") because it does not start at the beginning of the shard: `reset()` sets `current_position = B * T`, so the first batch starts at token 16,384 of `edufineweb_train_000001.npy`.

```python
def load_tokens(filename):
    npt = np.load(filename)
    npt = npt.astype(np.int32) # added after video
    ptt = torch.tensor(npt, dtype=torch.long)
    return ptt

class DataLoaderLite:
    def __init__(self, B, T, split):
        self.B = B
        self.T = T

        assert split in {'train', 'val'}

        data_root = "dataset"

        shards = os.listdir(data_root)
        shards = [s for s in shards if split in s]
        shards = sorted(shards)
        shards = [os.path.join(data_root, s) for s in shards]
        self.shards = shards
        assert len(shards) > 0, f"no shards found for split {split}"
        if master_process:
            print(f"found {len(shards)} shards for split {split}")

        self.reset()

    def reset(self):
        # state, init at shard zero
        self.current_shard = 0
        self.tokens = load_tokens(self.shards[self.current_shard])
        self.current_position = self.B * self.T

    def next_batch(self):
        B, T = self.B, self.T
        buf = self.tokens[self.current_position : self.current_position+B*T+1]
        x = (buf[:-1]).view(B, T) # inputs
        y = (buf[1:]).view(B, T) # targets
        # advance the position in the tensor
        self.current_position += B * T
        # if loading the next batch would be out of bounds, advance to next shard
        if self.current_position + (B * T + 1) > len(self.tokens):
            self.current_shard = (self.current_shard + 1) % len(self.shards)
            self.tokens = load_tokens(self.shards[self.current_shard])
            self.current_position = B * T
        return x, y
```
